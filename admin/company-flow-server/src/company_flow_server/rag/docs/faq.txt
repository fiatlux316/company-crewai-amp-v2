# 환불 지침

## 신선 제품 환불 (과일, 야채, 생선, 고기, 즉석식품 중 초밥, 김밥, 치킨)
환불 기간: 구매일로부터 7일 이내
준비물: 영수증, 상품, 결제수단
처리 방법: 고객만족센터 방문 후 교환/환불 처리
영수증 분실 시: 결제 카드 또는 포인트 적립 휴대폰 번호로 영수증 확인 가능

## 비신선 제품 환불 (가공식품 포함 신선 제품 이외)
환불 기간: 구매일로부터 30일 이내
준비물: 영수증, 상품, 결제수단
처리 구분:
- 상품 불량: 담당자 상품 이상 확인 후 교환/환불
- 단순 변심: 정상상품 상태 확인 후 환불

## 타점 환불
원칙: 원칙상 불가하나 고객 편의를 위해 1회만 가능
조건: 환불 기간 내, 상품+영수증+결제수단 지참 후 고객만족센터 방문
제외 매장: FC점포(안양, 부천, 시화) 제외
추가 환불: 영수증 내 추가 환불 상품이 있는 경우 구매 점포에서만 처리 가능
브랜드별 제한: 일부 브랜드는 타점 환불 불가할 수 있음

# 분실물 처리 - 상품 금액 보관

## 구매 상품 분실 시 처리
- 구매 후 매장 내 분실한 상품은 습득 시 상품 금액으로 보관
- 영수증 확인 후 상품 금액으로 반환
- 일주일 이내 미방문 시 관할 경찰서 유실물센터 인계

## 고객 안내 멘트
- "다행히 문의 주신 상품이 현재 습득되어 상품 금액으로 보관중입니다"
- "영수증 지참 후 고객만족센터로 방문해 주시기 바랍니다"
- "습득물은 구매 영수증 확인 후 상품 금액으로 반환해 드립니다"

## 처리 절차
1. 분실 상품명과 구매 내역 확인
2. 습득 여부 조회
3. 상품 금액 보관 상태 안내
4. 영수증 지참 방문 요청
5. 일주일 미방문 시 경찰서 인계 안내

# 상품권 권종 정보
신세계상품권 판매 권종: 5천원, 1만원, 5만원, 10만원, 30만원, 50만원
※ 1천원권은 판매하지 않음

# 신세계상품권 권종 및 온라인 전환
신세계상품권 권종 (6종):
- 소액권: 5천원, 1만원, 5만원 (5만원권부터 홀로그램 적용)
- 고액권: 10만원, 30만원, 50만원

# 홀로그램(스크래치) 및 온라인 전환
- 홀로그램 상품권 (5/10/30/50만원권): 앞면 은박 스크래치를 긁어 핀번호(6자리)와 상품권 번호(13자리)를 입력하여 SSG페이 앱에서 즉시 충전
- 홀로그램 없는 상품권 (5천/1만원권): 이마트 상품권 데스크/고객센터를 방문하여 신분증 확인 후 오프라인 전환
- 주의사항: 홀로그램을 긁은 상품권은 오프라인 매장에서 사용할 수 없으므로 주의해야 합니다

# 홀로그램 없는 상품권 SSG머니 전환 방법
- 방법1: SSG.COM 앱 → MY SSG → 상품권전환 → 매장방문 → 권종선택 → SSG MONEY 전환신청 후 실물 상품권 지참하여 매장 방문
- 방법2: SSG.COM 아이디 확인 후 이마트(트레이더스) 상품권샵 직접 방문하여 온라인 사용 가능한 형태로 전환
- 매장방문 시 본인확인을 위해 신분증 지참 필요
- 제외점포: 이마트 안양점

# 홀로그램 상품권 권종교환
- 구매 영수증 없어도 1일 50만원 한도 내에서 상품권 권종 교환 가능
- 홀로그램 상품권 운영 권종: 50만원권, 10만원권
권종 교환:
- 구매영수증 지참 시 교환 가능
- 영수증 미지참 시 1일 1회 50만원 한도 교환 가능

# 영수증 재발행
상품권 구매 영수증 재발행 가능 여부:
- 상품권 구매 영수증도 일반 영수증과 마찬가지로 재발행 가능
- 개인정보 및 부정 사용 방지를 위해 조건 확인 필요

# 재발행 조건
- 방문 필요: 결제했던 해당 점포의 고객만족센터(또는 상품권샵) 직접 방문
- 준비물: 결제 시 사용했던 카드(법인카드 등)와 신분증 지참하여 본인 확인 후 재발행
- 현금 결제 시: 결제 일시, 금액, 구매 수량 등을 정확히 알고 있어야 조회 가능
- 이마트 앱 활용: 신세계포인트 적립 구매 시 이마트 앱 내 '영수증' 메뉴에서 최근 90일간 구매 내역 확인 및 모바일 영수증 확인 가능
- 상품권 권종 교환 등 증빙용 사용 시 실물 영수증 출력 요구할 수 있음

# 수표 결제
수표로 상품권 구매 가능 여부:
- 이마트 상품권샵에서 수표로 상품권 구매 가능
- 현금과 동일하게 수표 결제 가능

##수표 결제 절차:
- 확인 절차: 수표 뒷면에 성함, 연락처 기재 및 신분증 확인 절차 진행
- 주의사항: 평일 오후 3시 이후나 주말/공휴일에는 수표 권종에 따라 은행 조회 지연 가능
- 고액 수표의 경우 처리 시간이 걸리거나 제한될 수 있으니 미리 확인 권장

#네이버페이 사용법 상세 안내
네이버페이 삼성페이 기반 사용 방법:
- 네이버 앱 → 오른쪽 위 N Pay(네이버페이) → 결제 화면에서 '삼성페이' 버튼 클릭
- 상단에 QR 결제 말고 삼성페이 탭 선택
- 삼성페이를 원래 사용하지 않아도 네이버페이만 있으면 결제 가능
- 네이버페이 앱이 삼성페이처럼 단말기에 결제 신호(MST/NFC)를 보냄
- 셀프체크아웃에서도 사용 가능

#네이버페이 결제 제한사항
- 네이버포인트는 사용 불가
- 삼성페이 포인트 사용 불가
- 잔액 부족 시 타 카드 등으로 추가 결제 필요

#기타 결제수단 추가

- SSG페이에 각종 카드 등록 후 사용: 가능

- 평생교육바우처 카드: 사용 불가


#푸드코트 상품권 사용 정책

##일반적인 푸드코트 상품권 사용:
- 대부분의 이마트 푸드코트에서는 상품권 직접 사용 불가

- 일부 매장은 소액 상품권 이용 가능 (매장별 잔액 보유 상황에 따라 제한)
- 일부 임대매장(다이소 등)에서는 상품권 사용 불가
- 일부 푸드코트는 리뉴얼로 운영하지 않는 매장 있음


2-1. 신세계상품권 사용 방법 안내
Q. 신세계 상품권 사용방법 안내
A. 신세계 상품권은 전국 이마트 (에브리데이/트레이더스 포함) 및 신세계 백화점은 물론 쇼핑/외식/레저 등 다양한 가맹점에서 폭넓게 사용하실 수 있으며 전국 이마트 상품권샵에서 이마트몰 적립금으로 전환하여 사용이 가능 합니다.
상품권의 자세한 안내는 『신세계 상품권1를 참조하시기 바랍니다.
Q. 상품권 잔액을 현금으로 지급받는 기준은 무엇인가요?
A. 상품권은 해당 액면가 대비 60%이상 사용하신 경우에 한하여 그 잔액을 현금으로 돌려드리고 있습니다.
단, 1만원권 이하 상품권의 경우 액면가 대비 80% 이상을 사용하신 경우에 한하여 그 잔액을 현금으로 돌려드리고 있습니다.
기준 이하로 사용하신 경우에는 신세계 상품권으로 잔액을 지급하고 있사오니 참고하여 주시기 바랍니다.


2-2. 상품권 판매 키오스크
Q. 상품권 판매 키오스크 이용에 대해서 알고 싶어요
A. 상품권 판매 키오스크를 이용하여 매장 운영시간 내에 서비스를 받으실 수 있습니다.
키오스크 운영시간:
- 키오스크는 매장 운영시간에 맞춰 이용 가능
- 매장이 문을 닫으면 키오스크 접근 불가
- 시스템 종료 시간이 있으니 여유있게 방문 권장
신세계상품권 구입 (법인카드,현금,현금IC카드) : 구입시 상품권 봉투수량 선택가능
모바일 교환권/상품권 교환(바코드/교환권번호입력): 모바일 교환권은 등록 후 취소가 불가함
증정 상품권교환 : 영수증 바코드 스캔하여 처리진행
제휴 포인트 상품권 교환 : 삼성카드 제휴포인트, OK캐시백, E1, S-OIL
신세계포인트 상품권 교환 : 신세계포인트 바코드 스캔 또는 카드 삽입
신세계포인트 적립 : 영수증 바코드 스캔
※ 키오스크 입점 점포 확인 필요


2-3. SSG MONEY 전환
Q. 상품권을 SSG MONEY 전환가능 한가요?
A.
- 통합회원 : SSG.COM에 직접 회원가입한 고객
- 간편회원 : SNS(카카오, 네이버 등)를 통해 SSG.COM에 회원가입한 고객
* SSG.COM 통합관리시스템> 상품권전환금 승인처리 > 회원ID/명 검색>
"회원유형" 확인
통합회원 및 간편회원 모두 월 1천만원한도 내에서 전환이 가능하나, 대기금액으로 구분되는 금액이 다릅니다.
eX. 상품권 70만원을 상품권샵에 방문하여 전환요청한 경우
- 통합회원 : SSGMONEY 50만원 / 대기금액 20만원
- 간편회원 : SSGMONEY 10만원 / 대기금액 70만원
- SSGMONEY 결제 한도 (1회 최대 50만원)
간편회원의 SSGMONEY는 온라인에서만 사용 가능하며 통합회원이 오프라인(이마트매장)에서 SSGMONEY로 결제 시 1회 최대 결제금액은 50만원입니다.
(대기금액으로 100만원을 보유하고 있어도 한번에 50만원 초과 결제는 불가능, 분할결제 진행해야 함)
- 상품권샵>상품권전환금 철회 불가능
기존) 고객 요청 시 상품권전환금 철회 가능 (캐셔파트에서 SSG.COM
으로 유선 철회요청)
변경) 상품권샵에서 상품권전환금 철회 불가능 고객이 직접 SSG.COM, SSGPAY 앱, SSGPAY 고객센터를 통해 출금 (환불) 진행해야 함

2-4. 신세계상품권 결제수단
Q. 신세계 상품권 결제수단이 어떻게 되나요?

2-5. 신세계상품권 분실

Q
신세계 상품권 분실로 사용중지가 가능한가요?
A
도난 / 분실 상품권은 사용중지 처리가 불가합니다.
- 상품권은 무기명 증권으로 상품권 소지자가 권리행사가 가능하기 때문에 사용중지 처리 불가
Q
신세계 상품권 분실로 상품권 번호 확인이 가능한가요?

상품권 번호를 확인하는 것은 어떠한 경우에도 불가합니다.
- 영수증을 소지하고 있더라도 상품권 번호를 확인할 수 없으며, 당사는 영수증별, 판매시간대별, 결제수단별로 상품권번호를 매칭하여 관리하지 않음

2-17. 신세계 상품권-증정상품권
(ver. 2023.07)
Q
신세계 상품권(증정상품권) 사용기준?
• 증정용 상품권은 교환' 불가, 사용만 가능 : 일반 상품권과 교환 불가 (동일 권종)
: 권종 교환 불가
﻿﻿SSG머니로는 전환 가능
﻿﻿이마트에서는 '현금영수증' 발행 가능 : 발급처인 백화점에서는 불가, 이외 타 계열사에서는 현금영수증 발행 가능
﻿﻿잔액 거스름돈은 이마트와 지급 기준 동일 : 60% 이상 사용시 현금 거스름 가능
(1만원권 이하는 80% 이상 사용)
* 사용기한 없음 (일반 상품권과 동일)


신세계상품권 권종 (7종) 소액권: 5천원, 1만원, 5만원 (5만원권부터 홀로그램 적용) 고액권: 10만원, 30만원, 50만원
홀로그램(스크래치) 및 온라인 전환 홀로그램 상품권 (5/10/30/50만원권): 앞면 은박 스크래치를 긁어 핀번호(6자리)와 상품권 번호(13자리)를 입력하여 SSG페이 앱에서 즉시 충전. 홀로그램 없는 상품권 (5천/1만원권): 이마트 상품권 데스크/고객센터를 방문하여 신분증 확인 후 오프라인 전환. 주의사항: 홀로그램을 긁은 상품권은 오프라인 매장에서 사용할 수 없으므로 주의해야 합니다.
전환 및 사용 방법 권종 교환 답변 수정해주세요

[상품권 권종 교환 기준]
권종교환 지침:
1. 구매영수증 지참 시: 금액 제한 없이 교환 가능 (상품권 내역조회 후 영수증과 상품권 일치여부 확인)
2. 영수증 미지참 시: 1일 1회 50만원 한도 내에서 교환 가능
3. 소액상품권 다량을 고액권으로 교환하거나, 소량을 상습적으로 고액상품권으로 교환해가는 고객들은 변칙환불 가능성이 있으므로 반드시 영수증을 확인
4. 종이권 ↔ 종이권, 기프트카드 ↔ 기프트카드 교환가능
5. 종이권 ↔ 기프트카드 교환불가(발행기관 상이)
6. 타사상품권 교환은 불가
7. 증정상품권은 교환 불가

상품권사용관련_신세계상품권사용방법Q: 5만원 할인쿠폰 사용 시 1만원권 상품권도 함께 사용할 수 있나요?A: 네, 결제수단은 상관이 없습니다. 할인쿠폰과 신세계상품권을 함께 사용하실 수 있습니다.
신세계상품권은 현금처럼 사용 가능하며, 전국 이마트(에브리데이/트레이더스 포함), 신세계 백화점, 쇼핑/외식/레저 등 다양한 가맹점에서 사용하실 수 있습니다.
상품권사용관련_신세계상품권사용방법Q: 2017년에 발행된 상품권도 사용가능한가요?A: 안녕하세요. 신세계 상품권은 발행일 상관없이 사용 가능합니다. 매장 결제시 사용 가능하며, 신세계상품권은 이마트 신세계백화점에서 사용 가능합니다. 감사합니다.
상품권사용관련_상품권잔액현금지급Q: 만원 상품권으로 만천원을 결제하고 잔돈을 받지 않고 왔는데, 어떻게 하면 받을 수 있나요?A: 상품권은 해당 액면가 대비 60% 이상 사용하신 경우에 한하여 그 잔액을 현금으로 돌려드리고 있습니다. 단, 1만원권 이하 상품권의 경우 액면가 대비 80% 이상을 사용하신 경우에 한하여 그 잔액을 현금으로 돌려드리고 있습니다. 기준 이하로 사용하신 경우에는 신세계 상품권으로 잔액을 지급하고 있사오니 참고하여 주시기 바랍니다.
상품권사용관련_상품권잔액현금지급Q: 상품권과 카드로 결제했는데 카드로 전액 지불로 나와서 문의드립니다.A: 상품권 결제 금액과 차액 금액 카드결제 내역을 확인하여 담당자에게 전달하여 문의 주신 번호로 연락드리겠습니다.
상품권사용관련_상품권사용처문의Q: 검단이마트 안 식당에서 신세계상품권을 사용할 수 있나요?A: 검단이마트의 경우 리뉴얼로 인해 현재 푸드코트나 식당을 운영하지 않고 있습니다.
일반적인 푸드코트 상품권 사용 안내:
 푸드코트에서는 상품권 직접 사용이 불가능합니다
다만, 카드결제 후 고객만족센터에서 상품권 결제로 변경하는 것이 가능한 경우가 있습니다
매장별로 운영 정책이 다를 수 있으니 해당 매장에 직접 문의하시는 것을 권장합니다
상품권사용관련_상품권사용처문의Q: 트레이더스 구성점 안경원에서 신세계 상품권 사용 가능한가요?A: 안녕하세요. 신세계상품권 사용 문의 주셔서 감사합니다.


트레이더스 내 입점한 안경원의 경우, 각 업체별로 상품권 사용 정책이 다를 수 있어 정확한 안내를 위해서는 해당 안경원에 직접 확인해 주시는 것이 가장 확실합니다.


번거로우시겠지만 방문 전 미리 전화로 문의해 주시면 헛걸음을 방지하실 수 있습니다. 혹시 매장 연락처가 필요하시면 도움드리겠습니다.

[BO 시스템 관리]

BO주문내역 상태 관리

Q: BO주문내역에서 결제 완료(입고푸시전송대기)는 무엇인가요?
A: 고객 결제 후, 주문서에서 [최종 인계 완료] 버튼을 눌러 고객만족센터에 상품 인계가 완료된 상태입니다. 상품 인계는 완료되었으나 픽업 시작일이 도래하지 않아 고객에게 입고 알림 푸시 및 교환증 발급 대기중이며, 픽업 시작일 오전 10시경 발급 후 '입고완료' 상태로 변경됩니다.


Q: BO 주문내역에서 '인계완료', '입고완료', '픽업완료' 명칭의 차이는 무엇인가요?
A: • 인계완료: 점포 가공 담당자가 주문 상품 실물 확인 후, 고객만족센터로 상품을 전달함 (BO 주문내역의 해당 주문 건 → 주문서 후 해당 팝업에서 인계완료를 클릭)
• 입고완료: 고객에게 상품 입고 알림 및 교환증을 발급함 (점포 가공 담당자가 고객만족센터 상품&주문서 전달하여, BO 주문서상 '인계 완료' 버튼 클릭하면 픽업 시작일 오전 10시경 입고완료로 상태 변경. 또는 결제완료 상태에서 [입고완료(교환증 발급)] 버튼 클릭 시 즉시 '입고완료' 상태로 변경되며 교환증 발급)
• 픽업완료: 고객이 상품을 픽업했음을 의미함 (주문내역에서 '픽업 완료' 버튼은 이마트앱 교환증으로 픽업완료 처리를 하지 못한 경우에 한해 사용)


고객 정보 확인

Q: 고객 성함, 연락처는 어디서 확인하나요?
A: 고객 성함은 BO주문내역에서 주문번호(파란 글씨) 클릭 시 주문내역에서 확인 가능합니다. 연락처는 고객 개인정보라 BO에서 확인 불가하며, 주문내역의 주문자명 괄호 안 CID(C+숫자8자리 조합)를 활용하여, 점포 내 사용중인 핀포인트 시스템 등 신세계포인트 회원 정보를 통해 확인해야 합니다.


주문서 처리

Q: 주문서 팝업에서 [점재고 인계 완료]와 [최종 인계 완료]의 차이는 무엇인가요?
A: 와인그랩 리뉴얼(25.11.27)과 함께, 점포 보유재고 상품과 후발주 상품(입고 예정)의 합주문이 가능하도록 변경되어, 주문 상품을 고객만족센터에 인계할 때 점재고와 후발주 상품 인계 여부를 구분하여 처리하고 있습니다.
• 점포 보유재고만 먼저 인계할 경우: [점재고 인계 완료] 클릭
• 후발주 상품까지 주문서상 모든 상품 인계 완료시: [최종 인계 완료] 클릭
※ [최종 인계 완료] 클릭시, 고객님께 입고 완료 알림톡/푸시가 발송되니 꼭 전체 인계 완료 후 클릭해 주세요.
※ 주문내역의 주문 상품 목록>주문유형 열에서 상품별로 보유재고/후발주 구분 확인 가능


Q: 실수로 BO에서 결제 취소를 해버렸어요. 다시 교환증 생성할 수 있나요?
A: 결제 취소 즉시 환불 처리가 진행되기 때문에, 다시 교환증 생성하는 것은 불가합니다. 고객님이 다시 와인그랩에서 주문을 해야 하고, 점포에 상품이 준비된 상황이라면 BO 주문내역에서 입고완료(교환증 즉시발급)을 클릭하면 새로운 교환증이 발급됩니다.


[재고 관리]

Q: 점포에 재고가 있는 상품인데 와인그랩에서는 픽업이 불가하다고 나옵니다. 왜 그런가요?
A: 보유재고 상품은 '최근 7일 픽업 점포 평균 판매량(=안전재고)'보다 시스템상 재고가 많을 경우만 와인그랩에서 판매합니다. 보유재고 상품은 와인그랩/내점 고객 동시 판매가 이루어지기 때문에, 와인그랩 주문 후 취소 발생 관련 고객 및 점포 문의가 많아 기능을 개선하였습니다. (※안전재고 기능은 25.12.23적용)


Q: 상품 인계하라는 블라썸 알림이 계속 와요. 왜 그런가요?
A: 점포에 진열된 보유재고(점재고) 상품은 와인그랩 고객 주문시 시스템상 재고가 차감되지만, 진열되어 있는 경우 실물 상품이 고객만족센터 인계 전 내점 고객에게 판매될 수 있습니다. 점재고 상품이 빠르게 인계될 수 있도록 인계완료 처리 전까지 정기적으로 알림을 발송하고 있습니다.
※ 재고가 확보가 어려운 상품이라면, 와인그랩 고객 주문 취소 처리 시 시스템상 재고는 원복됩니다. (반영 시간 30분 내외)


[픽업 관리]

픽업 일정

Q: 픽업일 변경 가능한가요?
A: 결제 이후 고객이 직접 픽업일을 변경할 수는 없습니다. 본사로 픽업일 변경 요청 문의 접수 시 상황에 따라 변경 가능합니다.


Q: 픽업일 종료 이후 수령이 가능한가요?
A: 픽업일 종료 이후에는 수령이 불가합니다.


픽업 자격

Q: 대리 수령 가능한가요?
A: 불가합니다. 주류는 법적으로 주문자 본인(성인) 신분증 확인 필수입니다. 신분증과 교환증 상의 성함 확인 후 상품을 받으실 수 있습니다.


[픽업 점포 설정]

Q: 픽업 점포는 어떤 기준으로 설정하나요?
A: 픽업 점포는 마이와인 - 픽업 점포 관리 / 장바구니 상단 / 상품 상세페이지 픽업정보 영역에서 언제든 변경할 수 있습니다. 해당 영역에서 한번이라도 점포를 변경하셨다면 마지막 변경 점포가 저장됩니다. 한 번도 점포를 설정한 이력이 없다면, 시스템 기본값으로 설정됩니다. (예시: 이마트는 은평점, 트레이더스는 스타필드 하남점)


Q: 결제 완료 후 픽업 점포를 변경할 수 있나요?
A: 결제 후 픽업 점포 변경은 불가합니다. '주문 내역'에서 직접 결제 취소 후 재주문 시 픽업 점포를 변경해주세요.


Q: 픽업 점포 선택 화면에서 내가 원하는 점포가 보이지 않아요.
A: 상품마다 픽업 가능한 점포가 다를 수 있습니다. 만약 픽업 점포목록에서 원하는 점포명이 보이지 않는다면 픽업이 불가한 상태이니 가까운 다른 점포를 이용하시기 바랍니다.


[교환증 관리]

Q: 구매한 상품을 픽업하고 싶습니다. 어떻게 하면 되나요?
A: 와인그랩으로 구매한 상품에 대해 점포 인계 준비가 완료되면, 픽업 시작일 이후 이마트앱 > 와인그랩 메뉴에서 교환증을 확인하실 수 있습니다. 상품 구매 시 선택하신 픽업 점포로 방문하신 후, 고객만족센터에서 직원에게 이마트앱의 교환증과 신분증을 보여주시면 상품을 픽업하실 수 있습니다.


Q: 교환증을 어디서 확인하나요?
A: • 교환증이 지급된 이후 사용 전이라면 이마트앱 > 와인그랩 메뉴 진입 시 메인/마이와인 화면의 오른쪽 하단 고정 버튼을 통해 바로 접근하실 수 있습니다.
• 이마트앱 쇼핑모드 → 픽업 메뉴에서도 확인 가능합니다.
※ 교환증은 픽업 기간 종료 이후 회수됩니다.
※ 픽업 기간 내 상품을 수령하지 않았을 경우(교환증 미사용 시) 해당 교환증은 더 이상 사용하실 수 없으며, 픽업 종료일 기준 +1일에 자동 환불 처리됩니다.


[서비스 대상]

Q: 전점에서 이용 가능한 서비스인가요?
A: 상품에 따라 특정 점포에서 픽업이 불가할 수 있습니다. 또한, 현재 이마트 FC점포는 와인그랩 서비스를 운영하지 않습니다.

Q: 와인그랩을 처음 사용하는데, 어떻게 해야 하나요?

A: 현대이지웰 복지포인트, 베네피아, e-제너두 복지포인트 사용이 가능합니다. 계산원에게 복지포인트 사용을 요청하신 후 바코드를 보여주시면 됩니다. 구매 불가 품목은 담배, 주류, 유가증권이며, 이마트 안양점과 부천점은 사용이 불가능합니다.

Q: 트레이더스 클럽 연회비가 어떻게 되나요?
A: 일반회원 스탠다드는 30,000원, 프리미엄은 70,000원입니다. 사업자전용 스탠다드비즈는 25,000원, 프리미엄은 70,000원입니다. 스탠다드회원은 TR캐시가 1% 적립되며, 프리미엄은 2% 적립됩니다.

Q: 우리모아포인트로 상품권 교환 되나요?
A: 우리 모아포인트는 5천점 이상 보유시 5천원 신세계 상품권으로 교환이 가능합니다.
[상품권 현금 전환 정책]
상품권현금전환_불가안내

Q: 상품권을 현금으로 바꿀 수 있나요?
A: 신세계 상품권은 현금과 교환할 수 없습니다. 단, 권종 금액 대비 60% 이상 사용 시 현금 잔돈 반환됩니다. 또한, 1만원권 이하 상품권의 경우 액면가 대비 80% 이상을 사용하신 경우에 한하여 그 잔액을 현금으로 돌려드리고 있습니다. 해당 기준 이하로 사용하신 경우에는 신세계 상품권으로 잔액을 지급하고 있는 점 참고하여 주시기 바랍니다.
